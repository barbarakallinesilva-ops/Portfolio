
# Portfólio Profissional — Barbara Kalline

## Sobre o projeto

Este projeto consiste em um portfólio profissional desenvolvido para apresentar minha trajetória acadêmica, habilidades, conhecimentos em tecnologia e objetivos profissionais.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Funcionalidades

- Apresentação pessoal e profissional.
- Exibição de habilidades técnicas e comportamentais.
- Apresentação de áreas do conhecimento e tendências tecnológicas.
- Galeria de projetos.
- Formulário de contato.
- Painel administrativo para gerenciamento de mensagens.
- Cadastro, edição e exclusão de mensagens.
- Exportação dos registros em formato JSON.
- Armazenamento de dados utilizando LocalStorage.
- Layout responsivo.

## Painel administrativo

O painel administrativo pode ser acessado pelo botão disponível no rodapé da página ou pelo atalho Ctrl + Shift + A.

Dentro do painel é possível visualizar, cadastrar, editar e excluir mensagens, além de exportar os registros em formato JSON.

O sistema utiliza o LocalStorage do navegador para armazenar os dados.

Quando não existem mensagens cadastradas, o sistema cria automaticamente 20 registros de teste para demonstrar as funcionalidades.

## Automação do formulário

Foi utilizada a proposta de integração com o serviço FormSubmit para encaminhamento das mensagens por e-mail.

A integração foi implementada no código, porém o recebimento e a ativação do serviço não foram confirmados durante os testes.

## Como executar

1. Baixe ou extraia a pasta do projeto.
2. Abra o arquivo index.html em um navegador.
3. Utilize o menu para navegar pelas seções do portfólio.
